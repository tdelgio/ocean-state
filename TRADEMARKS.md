platform.

grant rights to use the Ocean State name, logo, visual identity, domain names,
or branding in a way that suggests an official Ocean State product,
partnership, endorsement, or commercial affiliation.

You may:

- Refer to the project as Ocean State when describing compatibility,
  contribution history, or the upstream open-source project.
- Fork the code under the terms of the AGPL.
- Build a modified version if you clearly rename and rebrand it.

You may not, without written permission:

- Use Ocean State branding for a competing hosted service.
- Present a fork as the official Ocean State app.
- Use Ocean State logos, marks, or domains in a way that confuses users.

This policy is meant to keep the open-source project collaborative while
protecting the official product identity.
